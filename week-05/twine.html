Twine

Twine is a free, open-source tool for building interactive, branching stories by linking text passages together. Chris Klimas created it in 2009. It took off around 2012–13, thanks to the queer gaming community, with games like “Depression Quest”. It draws on older traditions such as choose-your-own-adventure books. It’s designed to be easy to use: passages appear as boxes, double brackets create links, and it needs no coding knowledge. The release of Twine democratized hypertext game creation. It allowed people to build choice-driven, node-based interactive stories exported to HTML web browsers.
